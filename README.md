# Learn Workout — step-by-step course

A workout tracking REST API built with **Express 5** and **Prisma 4**, one small step per commit.

Every step has:

- a commit with the code for that step
- a markdown file in [`docs/`](./docs) explaining what was done and which commands were run

## Steps

| #  | Step | Doc |
|----|------|-----|
| 01 | Project setup | [docs/01-project-setup.md](./docs/01-project-setup.md) |

## Follow along

Check out a single step with its commit:

```bash
git log --oneline
git checkout <commit-hash>
```
