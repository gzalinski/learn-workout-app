# Learn Workout — step-by-step course

A workout tracking REST API built with **Express 5** and **Prisma 4**, one small step per commit.

Every step has:

- a commit with the code for that step
- a markdown file in [`docs/`](./docs) explaining what was done and which commands were run

## Steps

| #  | Step | Doc |
|----|------|-----|
| 01 | Project setup | [docs/01-project-setup.md](./docs/01-project-setup.md) |
| 02 | Code formatting with Prettier | [docs/02-prettier.md](./docs/02-prettier.md) |
| 03 | Express server | [docs/03-express-server.md](./docs/03-express-server.md) |
| 04 | Dev tooling: nodemon and morgan | [docs/04-dev-tooling.md](./docs/04-dev-tooling.md) |
| 05 | Auth module: routes and controller | [docs/05-auth-module.md](./docs/05-auth-module.md) |
| 06 | Prisma setup (4.8.1) | [docs/06-prisma-setup.md](./docs/06-prisma-setup.md) |

## Follow along

Check out a single step with its commit:

```bash
git log --oneline
git checkout <commit-hash>
```
